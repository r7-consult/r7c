# Change Log

## v1.1.3

- Добавлено обновление самого `{r7} consult` прямо из интерфейса менеджера плагинов.
- В шапке магазина теперь отображается текущая локальная версия плагина.
- Если в удаленном репозитории доступна более новая версия, в шапке появляется плашка `Доступно обновление` и отдельная кнопка обновления.
- Исправлены визуальные ошибки в элементах интерфейса.

## v1.1.2

- Добавлена функция приоритета для плагинов. Теперь плагинам можно выставлять приоритет что поднять их выше в списке плагинов.

## v1.1.1

- Исправлено два бага с обновлением и установленными плагинами.
- Новое версионирование.
  - Первая цифра отвечает за большие изменения.
  - Вторая цифра отвечает за мелкие функциональные и визуальные изменения.
  - Третья цифра отвечает за фикс багов и мелкие изменения.

## v1.0.2

- Добавлена функция обновления плагинов прямо из интерфейса {r7c} consult (Менеджера плагинов).

## v1.0.1

- Минорные исправления в стилях и наименованиях.

## v1.0.0

Что нового
Каталог плагинов: карточки с превью, описанием, changelog, рейтингами и темизацией.
Установка/обновление/удаление: операции выполняются напрямую из редактора, без ручной сборки.
Динамический контент: welcome и license страницы, а также медиа грузятся из GitHub (r7c-packages) с актуальными данными.
Fallback при ошибке установки: если загрузка прерывается, пользователь получает модальное окно с альтернативной ссылкой на deploy.
Коммерческие плагины: отображение кнопки Learn More, проверка доступа перед установкой, трекинг событий.

Кому будет полезно
Поддержке — чтобы синхронно выкатывать обновления плагинов.
Разработчикам — для поставки собственных плагинов.
Пользователям — для установки «в один клик» и резервного скачивания готовых .plugin сборок.
