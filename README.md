# {r7} consult

`{r7} consult` — это менеджер плагинов для R7/ONLYOFFICE. Он помогает находить, устанавливать, обновлять и удалять расширения в одном окне, без ручной возни с файлами и лишних переходов.

## Что получает пользователь

- единый каталог с полезными плагинами для работы, обучения и автоматизации;
- быстрый просмотр описания, README, changelog и лицензии перед установкой;
- понятное управление уже установленными расширениями;
- удобный способ держать рабочее окружение в порядке.

## Когда особенно полезен

- когда нужно быстро подобрать подходящий инструмент под задачу;
- когда в команде используется несколько плагинов и важно не потерять контроль над версиями;
- когда хочется устанавливать и обновлять решения в пару кликов, а не вручную по папкам.

## Почему это удобно

`{r7} consult` экономит время и делает работу с расширениями предсказуемой: вы сразу видите, что устанавливаете, зачем это нужно и где посмотреть подробности.

## Поддержка

- Сайт: https://r7-consult.ru/
- Каталог решений: внутри `{r7} consult`
